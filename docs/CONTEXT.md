# Context

HelpmeSolder is past discovery. Vision is frozen. Build Phase 0+.

## One-liner

MCP-powered how-to solder guides for non-EE builders. Not an LLM. Not a simulator.

## Flow

Claude/Cursor plans in chat → MCP tools write a guide → secret URL shows prep → full wiring diagram → steps. Same URL updates when chat iterates.

## What this is

- A guide writer + renderer for soldering/wiring recipes
- Catalog-backed visuals (photo boards + skeleton SVG modules)
- Hard validation on pins/parts with alternatives

## What this is not

- Not a hosted chat LLM
- Not a circuit simulator
- Not freestyle LLM-drawn diagrams
