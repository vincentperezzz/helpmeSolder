# Expansion board thumbnails

Original SVG illustrations drawn for this project (licence: same as the repository). Each is 320x240, transparent background, soft shadow, no external resources and no brand logos. They are stylised drawings of each board family (shape, colour, connectors), not exact copies of any product. They are registered by `photoHint` in `src/lib/catalog/extra/boards-media.ts`.

Boards: arduino-leonardo, arduino-pro-mini, arduino-micro, arduino-nano-every, esp32-s3-devkitc, esp32-c3-devkitm, esp32-c3-supermini, esp32-cam, wemos-d1-mini, pi-zero-2w, pico-2w, teensy-40, blue-pill, digispark, microbit-v2, xiao-esp32c3, xiao-rp2040.
