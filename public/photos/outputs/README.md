# Output and driver thumbnails

Original flat illustrations (320x240, transparent background, soft shadow) for the motors,
relays, drivers, sound and light output parts in `src/lib/catalog/extra/outputs.ts`.
They are drawn for this project, contain no brand logos, and use the same licence as the
repository. Keyed by catalog `photoHint` in `src/lib/catalog/extra/outputs-media.ts`.
