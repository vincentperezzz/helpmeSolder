# Display and input thumbnails

Original SVG illustrations drawn for this project (licence: same as the repository). Each is 320x240, transparent background, soft shadow, no external resources and no brand logos. They are registered by `photoHint` in `src/lib/catalog/extra/displays-media.ts`.

- OLED: oled-ssd1306-128x32, oled-sh1106
- Colour TFT: tft-st7735, tft-st7789
- E-paper (paper-white panel, amber flat cable tail, small breakout board): epaper-1in54, epaper-2in13, epaper-2in9, epaper-4in2
- LED and LCD: tm1637, max7219-matrix, max7219-7segment, lcd-12864
- Inputs: keypad-3x4, keypad-4x4-buttons, ttp223, arcade-button, button-12mm-led
