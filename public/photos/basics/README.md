# Basics and electrics illustrations

Original SVG illustrations made for this project (licence: same as the repository). They follow the house style of `public/photos/basic/`: 320x240 viewBox, soft ground shadow, light from the top left, 2px outlines, transparent background. No brand logos or trademarked artwork; the only text is generic part numbers or values printed on the parts.

Registered in `src/lib/catalog/extra/basics-media.ts` by catalog `photoHint`.

Files (each as `<name>.svg`):

- LEDs: led-yellow, led-blue, led-white, led-orange, led-ir-940
- Resistors: resistor-100, resistor-330, resistor-470, resistor-2k2, resistor-4k7, resistor-47k, resistor-100k, resistor-1m (4-band colour code, gold tolerance)
- Capacitors: capacitor-ceramic-100nf, capacitor-electrolytic-10uf, capacitor-electrolytic-100uf, capacitor-electrolytic-1000uf
- Diodes: diode-1n4007, diode-1n4148, diode-1n5819, diode-zener-5v1 (band = cathode)
- Transistors: transistor-2n2222, transistor-2n3904, transistor-bc547 (TO-92), transistor-tip120 (TO-220), mosfet-irlz44n (TO-220), irf520-module
- Switches and connectors: switch-toggle-spst, switch-rocker, dc-jack-5521
- Power: regulator-7805, ams1117-33, lm2596-module, mt3608-module, tp4056-usbc
