# Basic part illustrations

Original SVG illustrations made for this project (licence: same as the repository). They share one style: 320x240 viewBox, soft ground shadow, light from the top left, 2px outlines, transparent background. The shapes follow how each part is drawn in the Wokwi diagram and how it looks on a breadboard.

Registered in `src/lib/catalog/media-basic.ts` by catalog `photoHint`. The older jpg/svg files in `public/photos/` are kept but are overridden by these.

Files: breadboard-half, buzzer-active, dip-switch-8, led-green, led-red, ntc-temperature, photoresistor, potentiometer, pushbutton, resistor-10k, resistor-1k, resistor-220, rgb-led, slide-potentiometer, slide-switch, tilt-switch (each as `<name>.svg`).
